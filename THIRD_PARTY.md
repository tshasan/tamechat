# Third-party code

The five classless stylesheets in `web/themes/` are vendored unmodified. Each is MIT-licensed according to its npm package metadata. The upstream repositories hold the authoritative copyright notices; consult them before redistributing.

| File | Project | Version | Author | Source |
|---|---|---|---|---|
| `simple.css` | Simple.css | 2.3.7 | Kev Quirk | https://github.com/kevquirk/simple.css |
| `water.css` | Water.css | 2.1.1 | Kognise | https://github.com/kognise/water.css |
| `mvp.css` | MVP.css | 1.18.0 | Andy Brewer | https://github.com/andybrewer/mvp |
| `pico.css` | Pico CSS (classless) | 2.1.1 | Lucas Larroche | https://github.com/picocss/pico |
| `sakura.css` | Sakura | 1.5.1 | Mitesh Shah | https://github.com/oxalorg/sakura |

The Go package `golang.org/x/net` (BSD-3-Clause) is used for HTML parsing. The demo talks to llama.cpp and other servers over HTTP and bundles none of them.

The sample answers in `corpus/` and `findings/` were generated by Qwen3.6-35B-A3B, which is released under its own licence; check it before reusing the text.
